เชื่อม Claude subscription

ระบบนี้ใช้ Claude Code ที่ติดตั้งใน container และล็อกอินด้วยบัญชี Claude ของคุณเอง เลือกวิธีใดวิธีหนึ่ง

  1. ล็อกอินใน container (แนะนำ)
    เปิด Terminal ของ container ใน Container Manager หรือ SSH เข้า NAS แล้วรัน 
    sudo docker exec -it ai-work-assistant claude auth login
    เปิดลิงก์ที่แสดงในเบราว์เซอร์ ล็อกอิน แล้วนำรหัสที่ได้มาวางใน terminal
  2. ใช้ token อายุ 1 ปี
    บนเครื่องที่มี Claude Code รัน claude setup-token แล้วใส่ค่าที่ได้ใน CLAUDE_CODE_OAUTH_TOKEN ของไฟล์ .env จากนั้นสั่ง Build/Start project ใหม่

หน้าเว็บนี้ไม่ขอและไม่เก็บรหัสผ่านหรือ token ของ Claude

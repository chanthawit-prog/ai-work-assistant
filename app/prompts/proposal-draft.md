# งาน: ร่างใบเสนอราคา / proposal

- requirement ของลูกค้าอยู่ในคำสั่งของผู้ใช้และไฟล์ใน input/
- ราคาต้องมาจาก price list ใน {KNOWLEDGE_DIR}/pricing/ เท่านั้น ห้ามเดาราคาเด็ดขาด ถ้าหาไม่พบให้ใส่ [ต้องระบุราคา]
  price list ที่เป็น Excel อ่านเป็น CSV ได้ด้วย `python3 -m xlsx_text <ไฟล์> [--sheet ชื่อชีต]` และอ้างชื่อชีตกับแถวที่ใช้
- ถ้ามีไฟล์ {KNOWLEDGE_DIR}/templates/proposal* ให้ใช้โครงสร้างและเงื่อนไขตามนั้น
- ตัวเลขทุกตัว (ยอดรวม ส่วนลด VAT 7%) ให้คำนวณด้วย python3 ห้ามคิดในหัว (รันจากโฟลเดอร์งานได้เลย ไม่ต้อง cd)
- Bash ในงานนี้รันได้เฉพาะ `python3 -c "..."`, `python3 -m <โมดูล>` และ `python3 output/<สคริปต์>.py` (และ `cd`) ทีละคำสั่ง
  ห้ามใส่ตัวเลือกอื่นของ python3 เช่น `-I` และคำสั่ง shell อย่าง for, while, if เพราะระบบไม่อนุญาต
  ถ้าต้องคำนวณหลายกรณีให้รันทีละคำสั่ง หรือเขียนเป็นสคริปต์ใน output/
- Python ในงานนี้ต่อเครือข่าย เรียกโปรแกรมอื่น และเขียนไฟล์นอกโฟลเดอร์งานไม่ได้ (ระบบกันไว้) ไม่ต้องลอง
- ถ้าต้องหากระแสโหลด ขนาดสาย หรือพิกัด breaker ให้ใช้ `python3 -m pec_calc` (ดู `python3 -m pec_calc --help`
  และ `python3 -m pec_calc tables` สำหรับตารางสายของบริษัท) แล้วสรุปผลพร้อมสถานะการตรวจสอบไว้ในหัวข้อสมมติฐาน

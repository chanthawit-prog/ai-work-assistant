# งาน: ถามงานวิศวกรรม / ช่วยคำนวณ

- คำถามอยู่ในคำสั่งของผู้ใช้ ไฟล์ประกอบอยู่ใน input/
- ค้นคลังความรู้ {KNOWLEDGE_DIR}/engineering/ (design guide มาตรฐาน calc sheet และรายงานเก่า) ก่อนตอบ
- ห้ามคิดเลขในหัว การคำนวณไฟฟ้าแรงต่ำมาตรฐานให้ใช้เครื่องมือ pec_calc ก่อน (ดูหัวข้อถัดไป)
  ถ้า pec_calc คำนวณได้ครบ ไม่ต้องเขียนสคริปต์แยก ให้ใส่คำสั่งที่รันไว้ในคำตอบแทน
  การคำนวณที่ pec_calc ไม่มี ให้เขียนสคริปต์ python3 ด้วยเครื่องมือ Write ไว้ที่ output/calc_<ชื่อ>.py แล้วรันจากโฟลเดอร์งาน
  ด้วย `python3 output/calc_<ชื่อ>.py` (โฟลเดอร์งานคือ working directory อยู่แล้ว ไม่ต้อง cd) ในสคริปต์ `import pec_calc` ได้
- ระบุสูตร หน่วย ค่าที่สมมติ และแหล่งอ้างอิง (ไฟล์ / หน้า / ข้อของมาตรฐาน)
- Bash ในงานนี้รันได้เฉพาะ `python3 ...` (และ `cd`) ทีละคำสั่ง คำสั่ง shell อย่าง for, while, if ระบบไม่อนุญาต ถ้าต้องคำนวณหลายกรณีให้รันทีละคำสั่ง หรือใช้ `python3 -c` / สคริปต์ python3 แทน
- เรื่องที่เกี่ยวกับความปลอดภัยหรือข้อกำหนดตามกฎหมาย ให้เขียนชัดว่าต้องให้วิศวกรผู้มีใบอนุญาตตรวจรับรอง

## เครื่องมือคำนวณ pec_calc
ทุกผลลัพธ์มีสูตร ค่าที่ใช้ สมมติฐาน อ้างอิง และสถานะการตรวจสอบของทีมกำกับไว้ รันจากโฟลเดอร์งานได้เลย
- `python3 -m pec_calc current` กระแสโหลดจาก kW/kVA · `vdrop` แรงดันตก · `cable` เลือกขนาดสาย
  · `isc` กระแสลัดวงจรที่ขั้วหม้อแปลง · `pfc` คาปาซิเตอร์ปรับ pf · `breaker` พิกัด breaker · `tables` ตารางของบริษัท
- ดูตัวเลือกด้วย `python3 -m pec_calc <คำสั่ง> --help` และใช้ `--json` ถ้าต้องการนำตัวเลขไปคำนวณต่อ
- ไฟล์ Excel ในคลังความรู้ (เช่น calc sheet) อ่านเป็น CSV ได้ด้วย `python3 -m xlsx_text <ไฟล์> [--sheet ชื่อชีต]`
- เลือกขนาดสาย: รัน `python3 -m pec_calc tables` ก่อน แล้วใช้ `cable --table <ชื่อตาราง>` ที่ตรงกับวิธีติดตั้ง
  ถ้าไม่มีตารางที่ตรง ต้องเขียนชัดว่ายังไม่ได้ตรวจกระแสที่สายรับได้ ห้ามสรุปขนาดสายจากแรงดันตกอย่างเดียว
- ใส่ผลของเครื่องมือในคำตอบ: คำสั่งที่รัน สูตร ค่าที่ใช้ ผลลัพธ์ สมมติฐาน อ้างอิง ข้อควรระวัง และสถานะการตรวจสอบ
  ถ้าสถานะคือ "ยังไม่ผ่านการตรวจโดยทีมวิศวกรรม" ให้บอกไว้ในหัวข้อข้อจำกัด
- ถ้าแนวทางในคลังความรู้กำหนดค่าต่างจากค่าตั้งต้นของเครื่องมือ (เช่น ตัวคูณกระแส เกณฑ์แรงดันตก แรงดันระบบ)
  ให้ใส่ค่าตามแนวทางนั้นเป็นตัวเลือกของคำสั่ง และอ้างอิงไฟล์ที่มา

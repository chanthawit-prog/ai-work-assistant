# เครื่องมือคำนวณ pec_calc

เครื่องมือคำนวณไฟฟ้าแรงต่ำที่ Claude เรียกใช้ในงาน **ถามงานวิศวกรรม** และ **ร่างใบเสนอราคา** เพื่อให้ใช้สูตรชุดเดียวกันทุกครั้ง
ทุกผลลัพธ์มีสูตร ค่าที่ใช้ สมมติฐาน แหล่งอ้างอิง และ **สถานะการตรวจสอบของทีม** กำกับไว้ วิศวกรจึงตรวจย้อนได้ทุกบรรทัด

เครื่องมือเป็นไฟล์ Python ไฟล์เดียว (`tools/pec_calc.py`) ใช้แค่ไลบรารีมาตรฐาน Claude รันด้วย `python3` เฉพาะตอนต้องคำนวณ
จึงไม่มีโปรแกรมค้างอยู่ใน RAM ของ NAS (ต่างจาก MCP server ที่ต้องเปิดค้างไว้)

> สถานะปัจจุบัน: **ยังไม่ผ่านการตรวจโดยทีมวิศวกรรม** ผลลัพธ์จะบอกสถานะนี้ทุกครั้งจนกว่าทีมจะรับรองตามหัวข้อ "การรับรองโดยทีม"

## คำสั่ง

| คำสั่ง | ใช้ทำอะไร | ตัวอย่าง |
|---|---|---|
| `current` | กระแสโหลดจาก kW (มอเตอร์ใส่ประสิทธิภาพ) หรือ kVA | `python3 -m pec_calc current --kw 75 --v 400 --pf 0.85 --eff 0.94` |
| `vdrop` | แรงดันตกในสาย จาก R และ X หรือจากค่า mV/A/m | `python3 -m pec_calc vdrop --amps 135.5 --length 80 --size 70` |
| `cable` | เลือกขนาดสายที่ผ่านทั้งกระแสที่รับได้และแรงดันตก | `python3 -m pec_calc cable --amps 135.5 --length 80 --table cv-4c-tray` |
| `isc` | กระแสลัดวงจร 3 เฟสที่ขั้วแรงต่ำของหม้อแปลง | `python3 -m pec_calc isc --kva 1000 --v 400 --z 6` |
| `pfc` | ขนาดคาปาซิเตอร์ปรับปรุง power factor | `python3 -m pec_calc pfc --kw 100 --pf-from 0.75 --pf-to 0.95` |
| `breaker` | พิกัด breaker มาตรฐานถัดไปจากกระแส × ตัวคูณ | `python3 -m pec_calc breaker --amps 135.5 --factor 1.25` |
| `tables` | รายการตารางของบริษัทที่ใช้ได้ | `python3 -m pec_calc tables` |

ทุกคำสั่งมี `--help` และ `--json` (ผลแบบ JSON สำหรับคำนวณต่อ) ค่าตั้งต้น: ระบบ 3 เฟส 400 V, pf 0.85,
ตัวนำทองแดง 90°C (XLPE), X = 0.08 Ω/km, เกณฑ์แรงดันตก 3%, ตัวคูณกระแสออกแบบ 1.25 ทุกค่าเปลี่ยนได้ด้วยตัวเลือกของคำสั่ง
และ Claude ถูกสั่งให้ใช้ค่าตามแนวทางในคลังความรู้ถ้ามี

ลองรันเองบน NAS ได้ด้วย
`sudo docker exec -e PEC_CALC_KNOWLEDGE=/data/knowledge -w /opt/app/tools ai-work-assistant python3 -m pec_calc tables`

## ข้อมูลที่ใช้

**อยู่ในเครื่องมือ** (ค่าตามมาตรฐาน)
- ความต้านทาน DC สูงสุดของตัวนำตีเกลียว class 2 ที่ 20°C ทองแดง 1.5–630 mm² และอะลูมิเนียม 16–630 mm² จาก IEC 60228 ตาราง 2
- ปรับความต้านทานตามอุณหภูมิด้วย R = R20 × (1 + α(θ − 20)), α ทองแดง 0.00393 อะลูมิเนียม 0.00403 ต่อ °C

**ของบริษัท** (ทีมวิศวกรรมเป็นเจ้าของ) วางไว้ที่ `knowledge/engineering/tables/` เป็นไฟล์ CSV เช่น
กระแสที่สายรับได้ตามวิธีติดตั้ง และค่า mV/A/m จากผู้ผลิตสายหรือมาตรฐานที่บริษัทใช้

```csv
# title: สาย CV ทองแดง 4 แกน บน cable tray เจาะรู อุณหภูมิแวดล้อม 40°C
# source: ตาราง ... ของ ... (ฉบับ/ปี)
size_mm2,ampacity_a,mv_per_a_m
35,125,1.10
50,150,0.82
```

- ต้องมีคอลัมน์ `size_mm2` และอย่างน้อยหนึ่งใน `ampacity_a` หรือ `mv_per_a_m`
- บรรทัด `# title:` และ `# source:` จะถูกพิมพ์เป็นแหล่งอ้างอิงในผลลัพธ์ ใส่ให้ครบเพื่อให้ตรวจย้อนได้
- บันทึกจาก Excel เป็น **CSV UTF-8** ได้เลย ตัวอย่างอยู่ที่ `examples/knowledge/engineering/tables/` (ค่าตัวอย่าง ไม่ใช่ค่าตามมาตรฐาน)
- หนึ่งไฟล์ต่อหนึ่งเงื่อนไขการติดตั้ง ตั้งชื่อไฟล์ให้บอกเงื่อนไข เช่น `cv-4c-tray-40c.csv`, `cv-1c-conduit-40c.csv`

ถ้าไม่มีตารางที่ตรงกับการติดตั้ง คำสั่ง `cable` จะตรวจได้แค่แรงดันตก และผลลัพธ์จะเขียนว่า
"ยังไม่ได้ตรวจกระแสที่สายรับได้" เสมอ

## การรับรองโดยทีม

1. วิศวกรผู้ตรวจรันกรณีทดสอบด้านล่างทีละฟังก์ชัน เทียบกับการคำนวณมือหรือ calc sheet ของบริษัท
2. ฟังก์ชันที่ผ่าน ให้บันทึกใน `knowledge/engineering/calc-verified.json` (ตัวอย่างใน `examples/knowledge/engineering/`)

   ```json
   {"vdrop": {"by": "ชื่อวิศวกร (เลขใบอนุญาต)", "date": "2026-11-15", "version": "1.0", "note": "ตรวจกับ C4–C6"}}
   ```

3. ผลลัพธ์ของฟังก์ชันนั้นจะขึ้น "สถานะการตรวจสอบ: ตรวจแล้วโดย ... เมื่อ ..." แทน "ยังไม่ผ่านการตรวจ"

การรับรองผูกกับเวอร์ชัน (`version`) ถ้าเครื่องมือออกเวอร์ชันใหม่ สถานะจะเปลี่ยนเป็น "ต้องตรวจใหม่" เอง
คลังความรู้เป็นแบบอ่านอย่างเดียวสำหรับ Claude จึงมีแต่คนในทีมที่แก้ไฟล์รับรองได้

## กรณีทดสอบสำหรับตรวจ

ค่าที่คาดหวังคำนวณมือไว้ และเป็นชุดเดียวกับที่ `tests/test_calc.py` ตรวจทุกครั้งที่แก้โค้ด

| กรณี | คำสั่ง | ผลที่คาดหวัง |
|---|---|---|
| C1 | `current --kw 75 --v 400 --pf 0.85 --eff 0.94` | 135.49 A (ที่ 380 V: 142.62 A) |
| C2 | `current --kva 1000 --v 400` และ `current --kw 2.2 --v 230 --phase 1 --pf 0.9` | 1,443.38 A และ 10.63 A |
| C3 | ความต้านทาน 35 mm² ทองแดงที่ 90°C | 0.524 × (1 + 0.00393 × 70) = 0.6682 Ω/km |
| C4 | `vdrop --amps 100 --length 100 --size 35` | 10.57 V = 2.64% ของ 400 V |
| C5 | `vdrop --amps 16 --length 30 --size 2.5 --temp 70 --pf 1 --v 230 --phase 1` | 8.51 V = 3.70% (ไม่ผ่าน 3%) |
| C6 | `vdrop --amps 135.5 --length 80 --mv-per-am 0.57` | 6.18 V = 1.54% |
| C7 | `isc --kva 1000 --v 400 --z 6` · เพิ่ม `--source-mva 500` · เพิ่ม `--c 1.05` | 24.06 kA · 23.28 kA · 25.26 kA |
| C8 | `pfc --kw 100 --pf-from 0.75 --pf-to 0.95` | 55.3 kvar |
| C9 | `breaker --amps 135.5` · `breaker --amps 128` | 200 A · 160 A |
| C10 | `cable --amps 135.5 --length 80 --table <ตารางตัวอย่าง>` · เพิ่ม `--derate 0.85` | 70 mm² · 95 mm² |

## ข้อจำกัด

- ไฟฟ้าแรงต่ำเท่านั้น และโหลด 3 เฟสสมดุล
- แรงดันตกไม่คิด skin effect และ proximity effect ซึ่งมีผลมากขึ้นกับสายขนาดใหญ่
- กระแสลัดวงจรเป็นวิธีอย่างง่ายที่ขั้วหม้อแปลง รวมอิมพีแดนซ์แบบขนาด ไม่รวมกระแสจากมอเตอร์และอิมพีแดนซ์ของสายหลังหม้อแปลง
- พิกัด breaker เป็นค่ามาตรฐานทั่วไป ต้องตรวจกับแคตตาล็อกที่ใช้จริง และวงจรมอเตอร์ต้องใช้เกณฑ์ของมาตรฐานและผู้ผลิต
- เครื่องมือไม่มีตารางกระแสที่สายรับได้ในตัว ต้องมาจากตารางที่ทีมตรวจแล้ว
- ผลทุกอย่างเป็นตัวช่วยออกแบบ งานที่เกี่ยวกับความปลอดภัยหรือข้อกำหนดตามกฎหมายต้องให้วิศวกรผู้มีใบอนุญาตตรวจรับรอง

## เพิ่มฟังก์ชันใหม่ (สำหรับผู้พัฒนา)

1. เขียนฟังก์ชันใน `tools/pec_calc.py` ที่คืนค่าด้วย `result(...)` ให้ครบทั้งสูตร ขั้นตอน สมมติฐาน อ้างอิง และข้อควรระวัง
2. เพิ่มคำสั่งใน `build_parser()` และ `run()`
3. เพิ่มกรณีทดสอบที่คำนวณมือไว้ใน `tests/test_calc.py` และตารางกรณีทดสอบด้านบน
4. ถ้าแก้สูตรเดิม ให้เพิ่ม `VERSION` เพื่อให้การรับรองเดิมกลายเป็น "ต้องตรวจใหม่"
5. บอก Claude ให้ใช้คำสั่งใหม่ใน `app/prompts/eng-qa.md`

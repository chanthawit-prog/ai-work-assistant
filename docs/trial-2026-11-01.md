- ข้อมูลตัวอย่าง: โปรไฟล์ลูกค้า ACME, price list (ราคาสมมติ), แนวทางเลือกขนาดสาย (ค่าสมมติ ไม่ใช่ค่าตามมาตรฐาน),
  transcript ประชุมภาษาไทย 19 บรรทัด

## สิ่งที่ได้ผลดี

- **สรุปประชุม** มีตารางกำหนดการ ระบุวันที่ที่ตีความเอง ("ศุกร์หน้า" = 6 พ.ย.) และคำนวณว่า lead time 6–8 สัปดาห์
  ทำให้ของมาไม่ทันหยุดปีใหม่ ซึ่งในประชุมไม่มีใครพูดถึง และค้นโปรไฟล์ลูกค้าในคลังความรู้มาเติมบริบทเอง
- **action_items.json** ถูกรูปแบบ อนุมัติแล้วเข้ารายการติดตามงาน 8 รายการ
- **คุยต่อ** ใช้ `--resume` กับ session เดิมได้จริง Claude จำวันที่และประเด็นจากรอบแรกได้ครบ
- **ใบเสนอราคา** ราคาตรงกับ price list ทุกบรรทัดพร้อมรหัสสินค้า ยอดรวมคำนวณด้วย `python3`
  (397,200 + VAT 27,804 = 425,004 บาท ตรวจด้วยมือแล้วถูก) และระบุสิ่งที่ต้องยืนยัน เช่น แรงดันระบบ
- **ความซื่อตรง** เมื่อรัน Python ไม่ได้ Claude เขียนชัดว่าตัวเลขเป็นการประมาณด้วยมือและต้องตรวจสอบ
- **แจ้งเตือน** ส่งครบทุกงานที่จบด้วยสถานะรอตรวจ (5 ครั้ง) พร้อมลิงก์ที่ถูกต้อง
- **Word** ส่งออกใบเสนอราคาได้ จัดหน้า A4 ตัวอักษร TH Sarabun New ตารางหัวสีเทา และ title block ท้ายเอกสาร
- ไม่มี error ฝั่งหน้าเว็บ ไม่มีการถูกปฏิเสธสิทธิ์นอกเหนือจากกรณีข้อ 3

## ปัญหาที่พบและแก้แล้ว

1. **รัน Python ไม่ได้เมื่อ Claude ใช้ `cd ... && python3 ...`** — กฎเดิมอนุญาตเฉพาะ `Bash(python3 *)`
   แต่ Claude Code ตรวจสิทธิ์ทีละส่วนของคำสั่งที่ต่อกันด้วย `&&` จึงเพิ่ม `Bash(cd *)` และบอกใน prompt ว่ารันจากโฟลเดอร์งานได้เลย
   ทดสอบซ้ำแล้วผ่าน
2. **path ยาวบน timeline** — ย่อเป็น `knowledge/...` และ "โฟลเดอร์งาน" ทั้งในการอ่านไฟล์และในคำสั่งที่รัน
3. **งานที่สร้างผ่าน API โดยไม่ใส่ชื่อ** ได้ชื่อเป็นชนิดงาน ตอนนี้ใช้บรรทัดแรกของข้อความเหมือนหน้าเว็บ

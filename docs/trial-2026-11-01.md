1. **รัน Python ไม่ได้เมื่อ Claude ใช้ `cd ... && python3 ...`** — กฎเดิมอนุญาตเฉพาะ `Bash(python3 *)`
   แต่ Claude Code ตรวจสิทธิ์ทีละส่วนของคำสั่งที่ต่อกันด้วย `&&` จึงเพิ่ม `Bash(cd *)` และบอกใน prompt ว่ารันจากโฟลเดอร์งานได้เลย
   ทดสอบซ้ำแล้วผ่าน
2. **path ยาวบน timeline** — ย่อเป็น `knowledge/...` และ "โฟลเดอร์งาน" ทั้งในการอ่านไฟล์และในคำสั่งที่รัน

## รอบที่ 10 (2 พ.ย. 2569): Docker image ใหม่ และตรวจความพร้อม

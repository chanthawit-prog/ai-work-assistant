# แม่แบบ (templates/)

ระบบมองหาไฟล์ในโฟลเดอร์นี้ 2 แบบ

| ไฟล์ | ใช้เมื่อ | ทำอะไร |
|---|---|---|
| `proposal*.md` (หรือ `.txt` `.docx`) เช่น `proposal-ตัวอย่าง.md` ในโฟลเดอร์นี้ | งาน **ร่างใบเสนอราคา** | Claude ใช้โครงหัวข้อและเงื่อนไขมาตรฐานจากไฟล์นี้ (ยืนราคา การชำระเงิน การรับประกัน ข้อยกเว้น) แทนการคิดเอง แก้ให้เป็นเงื่อนไขจริงของบริษัท |
| `report-template.docx` | ปุ่ม **ดาวน์โหลด Word** และไฟล์ Word ใน library | ระบบใช้หัวกระดาษ ท้ายกระดาษ โลโก้ และ style จากไฟล์นี้ แล้วใส่เนื้อหาของ Claude แทนเนื้อหาเดิม ทำจาก Word: ตั้งหัว-ท้ายกระดาษและโลโก้ให้เรียบร้อย ใส่ข้อความอะไรก็ได้ในเนื้อหา แล้วบันทึกชื่อนี้ |

ไม่มี `report-template.docx` ก็ได้ ระบบจะใช้รูปแบบตั้งต้น (A4 ฟอนต์ Anuphan หัวข้อสีน้ำเงินเข้ม title block ท้ายเอกสาร)

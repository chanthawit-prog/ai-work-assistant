# คลังความรู้ตัวอย่าง (โครงเริ่มต้นสำหรับวางบน NAS)

โฟลเดอร์นี้คือโครงของ `knowledge/` ที่ระบบใช้ คัดลอกทั้งหมดไปวางใน shared folder `ai-assistant/knowledge/` บน NAS
(File Station ลากวางได้) แล้วแทนไฟล์ตัวอย่างด้วยของจริงทีละไฟล์ ไฟล์ตัวอย่างทุกไฟล์มีคำว่า "ตัวอย่าง" ในชื่อหรือในเนื้อหา
ลบออกเมื่อมีของจริงแล้ว เพื่อไม่ให้ Claude หยิบราคาหรือค่าตัวอย่างไปใช้

| โฟลเดอร์ | ใส่อะไร | ระบบใช้ทำอะไร |
|---|---|---|
| `customers/<ชื่อลูกค้า>/profile.md` | ผู้ติดต่อ (ชื่อ ตำแหน่ง อีเมล) เงื่อนไขที่ใช้กัน มาตรฐานของลูกค้า ประวัติงาน ข้อสังเกต | หน้า **ลูกค้า**; Claude อ่านตอนร่างใบเสนอราคาและเตรียมพบลูกค้า; ฟอร์ม **ส่งอีเมล** หยิบที่อยู่อีเมลจากไฟล์นี้; ชื่อโฟลเดอร์คือชื่อที่กรอกในช่อง "ลูกค้า" ของงาน |
| `customers/<ชื่อลูกค้า>/` ไฟล์อื่น | ใบเสนอราคาเก่า สัญญา อีเมลสำคัญ (PDF, Word, ข้อความ) | ค้นได้จากหน้า **ถาม** และ `kb_search` ส่วนผลงานที่อนุมัติแล้วของลูกค้ารายนี้ระบบจำให้เองใน `data/library/` |
| `pricing/` | price list เป็น `.xlsx` หรือ `.csv` (คอลัมน์ รหัส รายการ spec หน่วย ราคา หมายเหตุ) | งาน **ร่างใบเสนอราคา** ใช้ราคาจากที่นี่เท่านั้น ไม่เดา ถ้าไม่พบจะใส่ [ต้องระบุราคา] |
| `engineering/` | design guide มาตรฐานที่บริษัทมีสิทธิ์ใช้ calc sheet รายงานเก่า (PDF ได้ รวมที่สแกน) | งาน **ถามงานวิศวกรรม** และหน้า **ถาม** อ้างอิง |
| `engineering/tables/*.csv` | ตารางสายของบริษัท (กระแสที่รับได้ตามวิธีติดตั้ง mV/A/m) | เครื่องมือคำนวณ `pec_calc` ดู `docs/calc-tools.md` |
| `engineering/calc-verified.json` | ฟังก์ชันของ pec_calc ที่วิศวกรตรวจรับรองแล้ว (คัดลอกจาก `calc-verified.example.json`) | ผลคำนวณจึงขึ้นว่า "ตรวจแล้ว" แทน "ยังไม่ผ่านการตรวจ" |
| `templates/` | เงื่อนไขมาตรฐานของใบเสนอราคา (`proposal*.md`) และแม่แบบ Word ของบริษัท (`report-template.docx`) | ใบเสนอราคาใช้โครงและเงื่อนไขจาก `proposal*` ส่วนไฟล์ Word ที่ดาวน์โหลดใช้หัว-ท้ายกระดาษจาก `report-template.docx` |

สิ่งที่ควรรู้
- ชนิดไฟล์ที่ค้นและอ่านได้: `.md .txt .csv .xlsx .docx .pdf` (PDF ที่เป็นภาพสแกนระบบอ่านด้วย OCR ให้) และรูปภาพ
  ไฟล์ `.xls` รุ่นเก่าให้บันทึกเป็น `.xlsx` ก่อน ชื่อไฟล์ห้ามขึ้นต้นด้วย `.` `@` `#`
- วางไฟล์แล้วรอไม่เกิน 30 นาที หรือเปิดหน้า **ระบบ → คลังความรู้** กด **อัปเดตดัชนีตอนนี้** แล้วดูรายการ "ไฟล์ที่อ่านไม่ได้" ว่าว่าง
- คลังความรู้ถูก mount แบบอ่านอย่างเดียวใน container Claude อ่านได้แต่แก้ไม่ได้ ถ้าจะแก้ไฟล์ให้แก้ผ่าน File Station หรือ Synology Drive
- ที่อยู่อีเมลที่ลงท้ายด้วย `.example` (ในไฟล์ตัวอย่าง) ระบบจะไม่นำไปใส่ฟอร์มส่งอีเมล แก้เป็นของจริงเมื่อใช้งาน
- ข้อมูลในโฟลเดอร์นี้ถูกส่งให้ Claude อ่านเมื่อเกี่ยวกับงาน ตรวจว่าเอกสารที่วางสอดคล้องกับ NDA ของลูกค้าและนโยบายบริษัท
  อย่าวางไฟล์ที่มีรหัสผ่านหรือข้อมูลส่วนบุคคลที่ไม่จำเป็น
